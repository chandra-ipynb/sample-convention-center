# Sample Convention Center

Responsive website for S.R.K Convention Centre in Neelasandra, Bengaluru.

## Preview locally

Open `index.html` directly, or serve the folder with:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deployment

This is a static website and can be deployed directly with GitHub Pages from the repository root.
